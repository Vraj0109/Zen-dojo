## Zen Dojo 0.5.0: CSES logic building, all 67 pattern articles, Windows judge fix, and workspace polish

Zen Dojo 0.5.0 brings the complete curated CSES logic-building problem collection, full 67-article DSA pattern reference library with C++ templates and mental models, automated handling for Windows Smart App Control blocked binaries, workspace layout refinements, and counted progress for custom content.

### Curated CSES logic-building collection (Plan 0029)
- **82+ verified CSES tasks** in optimal learning order with explicit "why" annotations explaining the core algorithmic leap for each problem.
- **Full spec files and test benches** across all major algorithmic categories:
  - Introductory Problems (Weird Algorithm, Missing Number, Repetitions, Number Spiral, Two Knights, Two Sets, Bit Strings, Trailing Zeros, Coin Piles, Palindrome Reorder, Gray Code, Tower of Hanoi)
  - Sorting and Searching (Distinct Numbers, Concert Tickets, Restaurant Customers, Movie Festival, Nested Ranges, Room Allocation, and more)
  - Dynamic Programming (Dice Combinations, Minimizing Coins, Grid Paths, Book Shop, Array Description, Edit Distance, Counting Towers, Projects, Elevator Rides)
  - Graph Algorithms (Counting Rooms, Labyrinth, Message Route, Round Trip, Monsters, Shortest Routes I & II, Course Schedule, Game Routes, Flight Routes)
  - Range Queries, Trees, Mathematics & String Algorithms (Static Range Minimum Queries, Dynamic Range Sum Queries, Subordinates, Tree Diameter, Exponentiation, Counting Divisors, String Matching)
- **Zero guesswork:** Every single problem output was verified against standalone reference implementations, backed by extensive stress tests and edge cases.

### All 67 DSA pattern articles complete (Plan 0008)
- Every single one of the 67 DSA patterns now has a full-length, deep article with C++ templates, time/space complexity analysis, mental models, and edge-case guides.
- Retired the legacy short-guide fallback on pattern pages in favour of the complete reference articles.
- Added an automated zero-tolerance test asserting all 67 pattern articles exist and remain populated.

### Windows Smart App Control & Blocked Binary Graceful Handling (Plan 0034)
- When Windows Smart App Control or aggressive endpoint antivirus blocks an unsigned compiled `main.exe` binary with `spawn UNKNOWN`, the judge no longer throws generic 500 errors.
- The editor immediately displays an informative, reassuring banner explaining the operating system restriction, confirms that Java and JavaScript remain fully functional, and automatically switches the language picker to Java (or JavaScript).
- Language choice is remembered per problem so users never hit repeated blocked spawn errors.
- Added a dedicated troubleshooting guide (`docs/troubleshooting.md`) linked from developer documentation.

### Workspace polish & layout verification (Plan 0028)
- Verified responsive layout across desktop (1440×900) and mobile (390px) viewports with zero horizontal overflow.
- Clean 28px top bar with keyboard shortcut toggle (`Ctrl+Shift+B`).
- Quick help text accessible via the `?` icon.
- One-click Save and `Ctrl+S` shortcut with saved state verification.
- Saved solutions displayed in the Notes tab with a "Load into editor" button.

### Progress counting for stored and custom content (Plan 0030)
- Problems installed via content packs or added through `pnpm content:add` now dynamically count toward pattern coverage badges and weekly roadmap completion totals.
