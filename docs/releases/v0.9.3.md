## Zen Dojo 0.9.3: new look, interview walkthroughs for every problem, and a pattern map for revision

### A new look
- The whole app moved to a new design: a fixed side rail on desktop and a tab bar on phones, with only the page content scrolling. Rounder shapes, softer colours, and themes you can edit, export and import (Profile, Settings).
- Tabs slide between options, and content fades in instead of sliding. Turning motion off in Settings stops all of it.
- Today, Practice, Learn, Review, Roadmap and Profile were all redone, and they keep working at in-between window widths.

### Practice and the problem page
- Practice lists every problem in one table with filters and sorting, and no more pages to click through. Problems are grouped by topic, the groups open and close, and Back returns you to where you were.
- The problem page has a slimmer header and a layout switcher. The results pane shows each test case's console output separately, plus custom input and your last runs (these sync to your phone).
- Shortcuts: **Ctrl+'** runs your code and **Ctrl+Enter** submits it.
- In system design and LLD projects you can run the open file or the whole project, so a class without `main` no longer fails to run.

### Interview walkthroughs
- Every one of the 486 built-in problems now has an interview walkthrough in its **Solution** tab, after Hints. It covers what to ask the interviewer first, examples to say out loud, the brute force and why it is too slow, the key observation, the optimal approach with its complexity, and how to test it out loud.

### Pattern map in Quick revise
- New **Pattern map** tab in Quick revise (`/revise?tab=map`), for spotting which pattern a new problem needs:
  - **Thinking map:** turn the input limits into a time budget, then follow a branching map from "what is the problem asking" to the pattern and its variation. Each pattern has when to use it, the key idea, what to watch out for, a short Python template and example problems, and shows how much of it you have solved.
  - **How to read a problem:** a six-step routine, a dictionary of 132 clue phrases (what each one points to and when it misleads), 30 worked examples with the reasoning hidden until you open it, and a table that maps what a brute force wastes to the pattern that fixes it.
  - **Pattern groups** (a map of all groups with your progress) and **Recall** (see a clue, name the pattern, then check).
- It covers every pattern in the app and every LeetCode topic tag.

### Smaller things
- The focus timer opens from a button and keeps running across pages.
- You can drop an image onto the Diagrams page to add it.
- Admins can edit problems and lessons with a live Markdown preview.
- AI: any GGUF model file can be added to Ollama from the app; the LM Studio provider was removed.
- Extra courses can be downloaded from the course library (first course: behavioural interviews).
- Fixed: `pnpm dev` showed a broken page when an older production build had run on the same address.
