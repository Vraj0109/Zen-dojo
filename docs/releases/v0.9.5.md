## Zen Dojo 0.9.5: brute force and optimal code, and new hints, for every problem

### Solution tab: from brute force to optimal
- Every one of the 486 built-in problems now shows the interview path in its **Solution** tab: the walkthrough, then **brute force code**, then the **optimal code**, each in C++, Java and Python with one language switch (it remembers your choice).
- For 315 problems the brute force has its own code that passes the normal tests, so you can see exactly what the slow version looks like and why it is too slow. For the other 171, where the direct approach is already the best one (a single pass, a formula), the tab says so instead of showing the same code twice.
- A few reference solutions were rewritten to match the approach the walkthrough calls optimal.
- **New hints for every problem:** 3-4 hints each, smallest nudge first, that lead to the optimal approach: how to look at the problem, the key observation, the technique, then the edge case that usually bites.

### Under the hood
- New checks keep this complete: `pnpm solutions:audit` compares each solution's complexity with its walkthrough, `pnpm solutions:verify --brute` runs the brute force code on the normal tests, and a test fails if any problem is missing brute force code (or the "already optimal" mark).
