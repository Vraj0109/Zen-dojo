## Zen Dojo 0.6.0: all 27 system designs, 24 Java LLD projects, 150 logic problems, special LeetCode harnesses

Zen Dojo 0.6.0 finishes the system design write-ups, grows the low-level design library, adds 150 logic-building problems from four sites, and makes six LeetCode problems that need custom test code runnable. It also carries the ADHD helper and accountability buddy. This note lists only what is in the repository; the CSES range, tree, mathematics, geometry and string sections are still in progress (see the end).

### System design: all 27 designs with architecture cards and scorecards (Plans 0014, 0031)
- All 27 system designs now have a deep write-up (`packages/shared/src/learn/design-depth-a.ts` to `design-depth-e*.ts`) and the page shows it: reference summary, diagrams, long sections, failure modes, Java for the key parts, follow-ups.
- Every one of the 27 has 4 or more **architecture cards** (what each component does, its scale, how it fails) and 4 or more **interviewer scorecard** rows (what a strong and a weak answer sound like). `design-depth.test.ts` enforces this for all of them, along with 3 or more captioned diagrams, 800 or more words and a failure-modes section.
- The seven designs that were short (metrics, Kafka, recommendations, building blocks, delivery slots, pricing, catalog) were lengthened and the test now asks for 1,500 or more words for them.
- The Java files in the write-ups are compiled and run by `apps/web/lib/design-code.test.ts`.
- Still open from Plan 0031: the older short walkthroughs were kept as a collapsed summary, not trimmed.

### Low-level design: 24 Java projects (Plans 0013, 0025)
- There are 24 LLD projects (the earlier releases had 10 to 11). Each has several Java files, a `Main` with expected output, tests, a walkthrough of 1,000 or more words in 6 or more sections, a class diagram and a sequence diagram. A guard test in `learn.test.ts` checks all of this.
- Added in this stretch: pub/sub, order book, text editor, job scheduler, digital wallet, API gateway, inventory and social feed, on top of parking lot, elevator, vending machine and ATM, cache and rate limiter, URL shortener, logger and notifications, movie booking, Splitwise, library, food delivery, cab, games, file system, key-value store, hotel and meeting rooms.
- `lld-projects.test.ts` compiles and runs 9 of them on every test run (the first one and the eight newest) when a JDK is present; CI installs JDK 17. The others were compiled by hand with `javac -Xlint:all` when written.

### 150 logic-building problems (Plan 0022)
- 150 problems in the "Logic building" set, written in our own words with a link to the original: Project Euler 44, AtCoder 35, Codeforces 46 and Kattis 25 (the counts by site follow the entries in `dsa.ts`; the total of 150 is exact).
- Each runs in the in-app judge, with a reference solution, 6 or more tests, 3 or more hints and large inputs. Expected outputs were produced by running the C++ reference, not by hand.
- Each site has its own pattern with a guide and a full article, and `/dsa` can filter by source (LeetCode, CSES, AtCoder, Codeforces, Project Euler, Kattis, cp-algorithms).
- Project Euler tasks take parameters, and none of the tests use the original published inputs.

### Special LeetCode problems now run (Plan 0022, Plan 0040)
These six had no spec before because they need custom test code. They now have specs in `problems-special.ts` and harness support in `apps/web/lib/judge/harness-special.ts`:
- lc-297 Serialize and Deserialize Binary Tree
- lc-173 Binary Search Tree Iterator
- lc-133 Clone Graph
- lc-528 Random Pick with Weight
- lc-382 Linked List Random Node
- lc-362 Design Hit Counter
A test checks that each has a starter template in every language and runs the C++ reference solution (skipped when `g++` is missing). Their large inputs are small, one case each. The Java and JavaScript reference solutions are not tested for these six.

### ADHD helper and accountability buddy (Plan 0035)
- Optional accountability buddy with three tones (calm, peer, coach), a sprint intention and a short reflection at the end. It is off by default and makes no network requests.
- Non-punitive wording when you come back after days away.
- A five-step "Micro-steps" tab in the problem workspace (restate, bounds, brute force, bottleneck, pattern), saved per problem.
- Zen mode (`Ctrl+Shift+Z`) dims counters and badges.
- Settings has a "Focus & Pacing" section for buddy mode, name and pacing.

### Related changes carried in this release
- Review pacing: Today shows at most 5 reviews and the rest sit in a Catch-up backlog drawer; the roadmap and settings can shift the schedule by +1 or +2 weeks; theme choices are stored in the database as well as the browser (Plan 0036). Open point: shifting does not mark a paused period for streaks, and the review cap is not adjustable in Settings yet.
- Study pages show one "On this page" rail; whole-course jumping moved into the breadcrumb, with previous and next links at the bottom (Plan 0037).
