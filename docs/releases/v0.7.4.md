## Zen Dojo 0.7.4: a pet companion you can chat with, a LeetCode-style profile, and a clearer Mac install

### Your Buddy is now a pet
- The Buddy is a small animated companion instead of a corner button. It has four moods: idle, thinking (while an AI answer is being written), sleeping and excited (all tests passed, sprint done). It says short encouraging lines now and then, in the tone you chose, and you can set how often (or never).
- **Throw it.** Drag the pet and let go: a flick slides it toward a screen edge with friction and it settles there with a small bounce. It only rests on edges, so it never sits in the middle of your work. The arrow keys send it to an edge too.
- **Pets from Petdex.** In Settings, Buddy, add any pet from petdex.dev: paste its link (for example `https://petdex.dev/pets/shinchan`) or upload the downloaded zip. The pet is animated by mood, waves while it talks and runs while you drag it. You can also import your own image. Zen Dojo includes no pets itself; there is a link to petdex.dev under the pet settings.
- **Chat with your pet.** With AI turned on, click the pet and open the Chat tab. It answers in character, using the pet's name and description. With "AI lines" on, its speech bubbles are written in the pet's voice too.
- Fixed: pet links whose page name differs from the file name (such as `luffy-2`) now import, and the importer follows Petdex's redirects safely.

### A profile like LeetCode's
- Portfolio (`/profile/portfolio`) now shows a solved ring split into easy, medium and hard, current and best streak, active days, a 16-week activity map, your badges with progress, and a card for every course you have started. Finished courses show as certified with a certificate you can print; courses partly done show their percentage.
- **Summarize** writes a plain summary of your work instantly. On your own pages, **Write it with AI** asks your chosen AI for a more natural version, using only the numbers on the page.
- The portfolio can be downloaded as a standalone web page. Public links come with the hosted site.

### Smaller things
- Ask AI works on course pages and has install guides for more AI tools (added in 0.7.3).
- New read-only `/admin/study` page, and two flaky tests made reliable.
- macOS: the install notes now cover macOS 15, where "right-click, Open" no longer works. Use System Settings, Privacy & Security, Open Anyway (or the one-line Terminal command).
