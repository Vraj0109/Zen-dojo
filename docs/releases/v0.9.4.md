## Zen Dojo 0.9.4: faster pages, a design patterns course, and LeetCode history by file

### Faster
- Pages load much less code. A problem page used to download and run about 7 MB of JavaScript (every problem in the app came along); it now loads about 0.7 MB, and other pages about the same. Opening and switching problems feels quicker, most of all on slower computers.
- Right after start the app quietly opens the main pages once in the background, so the first visit to Practice, a problem, Learn or Review is fast too.

### Design patterns in LLD
- New **Pattern catalogue** section in the Low-level design course: 27 lessons, one per pattern. All 23 classic patterns (factory method, abstract factory, builder, prototype, singleton, adapter, bridge, composite, decorator, facade, flyweight, proxy, chain of responsibility, command, iterator, mediator, memento, observer, state, strategy, template method, visitor, interpreter) plus object pool, dependency injection, null object and repository.
- Each lesson has the intent, a class diagram, a complete Java example from a real interview scenario (payments, parking lot, editor undo, chat room…), when to use it and when not to, how it shows up in LLD rounds, and the patterns it is confused with.

### LeetCode history by file
- The browser extension can now **Export to file**: it saves all your accepted LeetCode submissions (code, language, runtime, memory, time, notes) as a `zen-dojo-leetcode-….json` file. No pairing key or app address needed.
- In the app, **Profile → Settings → Connections → Import file** reads that file. Importing the same file again is safe.
- Sending straight to the app with a pairing key still works; it is now under "Send to the app directly (optional)". Reload the extension to get version 0.3.0.

### Fixes
- Tab rows that do not fit (on phones, in narrow panes) now scroll: with a mouse wheel on desktop, by swiping on phones. The side with more tabs fades out instead of cutting a label in half, and the selected tab is scrolled into view.
- Search fields no longer show a second box inside the rounded field when focused.
- In Quick revise, pattern chips that wrap onto two lines keep their padding.
- The extension popup has better contrast in light and dark mode.
