## Zen Dojo 0.7.1: sign in from the desktop app, a Java IDE in "Your classes", multi-select filters and search, clearer ticks, and deleting your data

This release makes sign-in work in the installed desktop app, turns the "Your classes" box on low-level design pages into a Java editor, adds multi-select filters and a deeper search to the problem list, shows solved ticks more clearly, and lets you delete your cloud data and this device's data separately.

### Sign in from the desktop app
- "Continue with GitHub" opens your normal browser. After you approve, the browser hands you back to Zen Dojo through a `zendojo://` link and the app window is signed in. Before, the browser finished the sign-in and the app stayed signed out.
- The first time, your browser asks whether to open Zen Dojo. That is expected.
- On Linux the link works only if your desktop environment handles `zendojo://` for AppImages (see `docs/troubleshooting.md`).
- If you sign in at `http://127.0.0.1:3000` in a browser, nothing changes.

### A Java editor in "Your classes" (low-level design)
- The "Your classes" box on LLD pages is now the multi-file Java editor: a tab per class, add and delete files, Run, and a console with output and compiler errors you can click.
- Your files are saved with the problem, come back when you reload, and sync to your other devices. Older plain-text answers open as `Main.java`. Limits: 30 files and 200 KB in total.
- If a save is refused (for example an invalid file name), the form now shows the reason instead of failing silently.
- System design pages keep the plain text box.

### Multi-select filters and deeper search (`/dsa`)
- Source, status, difficulty, topic and notes filters each accept several choices, with Select all, Clear, a Clear all link and removable chips for what is active. No choice in a filter means no filtering. Within one filter any chosen value matches; across filters all must match.
- Filters live in the address (`?difficulty=easy&difficulty=medium`), so they work without JavaScript and can be bookmarked. Old single-value links still work.
- Search now looks at titles, numbers, topics, pattern names, problem statements, hints and the test inputs and outputs. Every word you type must match. A search of digits only still means that problem number.

### Solved ticks
- Solved in Zen Dojo (every test passed) is one tick in the accent colour. Also solved on LeetCode adds a second, grey tick. Solved only on LeetCode is one faint grey tick.

### Delete your data, separately (Account page)
- **Delete my cloud data** removes what is stored under your account in the cloud, with an option to close the account. It does not touch the data on this device or others, and it unlinks this device so nothing is uploaded again unless you choose to. Limited to 3 per hour.
- **Delete data on this device** erases the progress stored here. It does **not** delete your cloud copy and queues no deletions for upload. Imported content and the extension pairing key are kept by default, and you are offered a backup first.
- Both need you to type `DELETE`. See `docs/account-data.md`.

### Smaller changes
- The Topic filter always has choices (pattern names fill in when LeetCode topics are not loaded), and filter buttons keep a fixed width so the row does not jump.

### Things to know
- Back up `data/habit.db` before trying the delete tools. The installer also copies it to `backups/` before a new version first starts.
- Not changed: study content pages in the admin portal are still not built; the phone layout has no account button yet.
- The desktop sign-in fix needs this installer: 0.7.0 apps cannot sign in from the desktop window, and updating installs it.

### Verification
- `pnpm check` passed on this release: lint, typecheck, the production build and 1,604 tests across 94 test files (17 skipped).
