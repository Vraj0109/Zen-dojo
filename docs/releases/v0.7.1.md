## Zen Dojo 0.7.1: multi-select DSA filters and full-text search, clearer solved ticks, independent data deletion, and LLD IDE fixes

Zen Dojo 0.7.1 brings powerful multi-select filtering and deep search across the DSA problem catalog, updates solved status ticks for clearer visual distinction between Zen Dojo and LeetCode solves, adds independent cloud data and local device deletion controls with typed confirmation, and fixes save error reporting in the multi-file LLD IDE.

---

### Solved ticks: Zen Dojo and LeetCode distinction
- **Accent tick for Zen Dojo solves**: A problem solved directly inside Zen Dojo (where your code passed all test cases in the built-in judge) is indicated by an accent-colored single tick.
- **Second grey tick for LeetCode**: When a problem has been solved both locally in Zen Dojo and on LeetCode, an accent tick is followed by a distinct second grey tick.
- **Faint tick for LeetCode-only**: Problems solved solely on LeetCode (not yet verified in Zen Dojo) continue to show a single muted tick.
- Accessible tooltips clearly describe whether a problem was solved here, on LeetCode, or both.

---

### Multi-select filters and deep search on `/dsa`
- **Multi-select dropdown filters**: The DSA catalog now supports choosing multiple values across:
  - **Source**: LeetCode, CSES, AtCoder, Codeforces, Project Euler, Kattis, and cp-algorithms.
  - **Status**: Not solved, Solved, Needs review, Solved again, and Stuck.
  - **Difficulty**: Easy, Medium, and Hard.
  - **Topic**: All roadmap topics (Trees, Graphs, DP, Arrays, Backtracking, etc.).
  - **Notes & Code**: Has notes, Has code, No notes.
- **Intuitive selection controls**: Each dropdown includes **Select all** and **Clear** shortcuts, along with active filter chips that can be dismissed individually or cleared all at once with **Clear all**.
- **URL-backed query state**: Multiple filter values serialize into URL query parameters (e.g. `?difficulty=easy&difficulty=medium`), making any filtered view bookmarkable and shareable without requiring client-side JavaScript. Within a filter category, multiple selections evaluate with `OR`; across categories, filters evaluate with `AND`.
- **Deep full-text search**: Search query `q` now matches not only problem numbers and titles, but also roadmap topics, pattern names, full problem statements, hints, and judge test case inputs/outputs.

### Account data deletion: cloud and device independently (Plan 0054)
Zen Dojo now provides two completely independent deletion tools on the Account page (`/profile/account`), giving users complete control over their data without risk of accidental cascade wipes:

1. **Delete my cloud data**:
   - Removes all synced rows associated with the user's account in Cloudflare D1 (`problem_solves`, `notes`, `tasks`, `solution_runs`, `pack_progress`, `practice_sessions`, `timer_rows`, `settings`, `sync_heads`, and `user_quota`).
   - Supports two scopes: `data` (clears synced progress while keeping your account and sessions) and `account` (clears synced data, revokes sessions, and removes the user record).
   - Rate-limited to 3 successful deletions per user per hour via Worker abuse protection.
   - Automatically unlinks the local device upon completion, ensuring local history is not unintentionally re-uploaded.
   - **Local data safety**: Does not touch the SQLite database on this or other local devices.
2. **Delete data on this device**:
   - Erases local progress stored in the device's SQLite database (`problem_solves`, `problem_notes`, `solution_runs`, `tasks`, etc.).
   - Truncates local sync tracking tables (`sync_dirty`, `sync_stamps`, `sync_ids`) and resets sync flags.
   - **Trigger silencing protection**: Operates with `sync_flags.applying = '1'` throughout the deletion transaction so that SQLite deletion triggers remain silent. This guarantees that **no DELETE mutations are placed in `sync_dirty`**, keeping your cloud copy completely safe in Cloudflare D1.
   - Preserves machine-specific installation settings (`extension_token`, `content_feed_url`) and imported packs by default.
3. **Explicit confirmation guard**:
   - Neither delete action can be triggered accidentally: each requires typing the word `DELETE` in capital letters and confirming the action.
   - Prompts users with a direct link to download a backup JSON file before proceeding.

### Multi-file Java LLD IDE fixes
- **Save error notification**: When saving multi-file Java LLD notes or projects fails (such as when exceeding storage quotas or encountering validation issues), the notes form now displays the exact server error message rather than silently failing.
- Clean separation of note limits and validation helpers between server and client modules.
