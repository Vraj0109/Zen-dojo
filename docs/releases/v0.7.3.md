## Zen Dojo 0.7.3: Ask AI on course pages, and install guides for AI tools

### Ask AI chat on every course page
- Concept lessons, system designs and low-level design problems now have an "Ask AI" button at the bottom right. It opens the same chat as on problems, with starters: *Explain this lesson*, *Quiz me* (one question at a time, with feedback), *Give me an example* and *Interview question*. You can also type your own question.
- The chat knows the lesson you are reading. It keeps your conversation while you scroll, close the panel or reload, until you press New chat.
- It uses the same answerer as the problem chat: the local model through Ollama by default, or Claude Code after you allow it in Settings.

### Get more AI tools
- Settings, Local AI now has "Get more AI tools". It shows the install command for your system (Windows, macOS or Linux) with a Copy button, a link to the tool's own documentation, and what to do after installing, for Claude Code, Gemini CLI, Codex CLI (ChatGPT), Ollama and the DeepSeek R1 model.
- Zen Dojo never runs these commands for you. Tools found on your computer show "Found on this computer".
- Any model already installed in Ollama (for example DeepSeek R1) now appears in the Model list.
- Gemini CLI and Codex CLI are included but not yet tested by us: use the Test button after installing.
- Antigravity is not offered: its command line cannot be limited to answering questions.
