## HabitManager 0.3.0: a calmer app, a real code editor, and one timer

This release is about making the app quieter to use every day. There are fewer places to click, the lists look like
LeetCode's, code is coloured, and the timer follows you around.

### What's new

**A simpler way around**
- The sidebar has five items: **Today, Practice, Learn, Review, Profile**. Everything else is a tab inside one of them
  (Learn has System design, LLD, Core CS, Reading list, Diagrams; Review has Due today and Quick revise; Profile has
  Stats, Roadmap, Settings). Old addresses still work.
- **Today** is one short "Up next" list (an interview countdown, reviews due, and today's tasks, at most five rows).
  Done tasks, this week's tasks and the week focus are folded away until you want them.
- **No emoji** anywhere. The DSA list reads like LeetCode's: a status mark, the title, the pattern and a coloured
  difficulty. Tabs are plain underlined text.

**One focus timer**
- A single timer in the sidebar keeps running while you move between pages, and survives a reload. Press
  **Start timer** on a problem, lesson or pattern; **Save** logs the minutes to that item.
- If you start something else while the first timer has time on it, the app asks whether to save that time first.

**Code you can read and write**
- All code is syntax-coloured for its language, in light and dark mode, with a **Copy** button.
- Where you write code (your solution, cheat-sheet templates, LLD classes) there is now a proper editor: line
  numbers, auto-indent, bracket matching and closing, Tab to indent, undo/redo and find. It still works with
  JavaScript turned off.

**Learning pages**
- Lessons read as one article with a contents list on the side. The "Remember" summaries moved to **Quick revise**,
  where they belong; lesson pages no longer break up the text.
- Pattern pages have **Learn**, **Practice** and **Reference** tabs. **Reference** holds 58 articles from
  [cp-algorithms](https://cp-algorithms.com) (proofs, variants, complexity and code) for the patterns they explain,
  with math, coloured code and credit. They work offline.
- DSA pages put the patterns first. Re-solves and other solves are tabs, and a problem page leads with the problem;
  hints stay hidden until you ask.

**Simple mode (on by default)**
- Hides the power tools so each page shows what to do next: the boss fight, pattern cheat sheets, diagrams, the
  reading list and the stuck-list history. Nothing is deleted. Turn it off in **Profile > Settings > Interface**.

### Good to know when updating
- **Simple mode is on after you update**, so the tools above will be hidden until you switch it off. Your data is
  untouched, and a backup is made before the new version first starts, as with every update.
- No database changes in this version.
- Windows and Linux (AppImage) update themselves on the next restart. On macOS the app tells you a new version
  exists and you install it by hand (the build is not signed).
