## Zen Dojo 0.9.7: content updates now arrive without an app update

### Lessons and problems come from one shared database
- Every built-in problem, test, hint, solution, lesson and list (the roadmap, pattern groups, reading list, quiz deck, thinking map) now lives in one shared content database instead of inside the app.
- A fix to a lesson or a new hint reaches you without a new version: the website shows it at once, and the desktop app downloads it on its next check.
- The desktop app downloads only the parts that changed. It tells you when something changed in a course you downloaded, and stays quiet about the rest. In *Profile, Settings, Offline content* you can follow or mute each course and pattern.
- The installer still carries the full content, so a fresh install works offline from the first start.
- If the content ever has to be rebuilt from scratch, the app notices and downloads a complete new copy on its own.

### For the admin
- A new editor at `/admin` for problems, lessons and lists. Pages are built from blocks (text, code, diagram, image) that you can add, remove and reorder, with a preview, a Markdown view, and a test run before saving.
- **Write with AI** on every field copies a prompt with the full context; paste the answer back and check it before saving.
- Every save is checked (errors block it), written to an audit log, and can be undone from the history.

### Under the hood
- The content files are gone from the repository (about 19 MB). Tests use a small committed sample of the content, and `pnpm test` no longer rebuilds every reference solution.
- New commands: `pnpm content:pull`, `content:snapshot`, `content:verify`, `content:verify-solutions`, `content:fixture`, `content:import`. A weekly workflow keeps a backup of the content.
- Problems you added one at a time with the old `content:add` command no longer show in the DSA list. Your past solves of them still count in the roadmap totals, and the rows stay in your backups.

### Fixed since 0.9.6
- The 0.9.6 installers were built without the app's own server and content, so they did not work, and installed apps never offered them as an update. 0.9.7 is the same release, built correctly.
