## Zen Dojo 0.4.0: a code judge, real Java projects, your own look, and a new name

HabitManager is now **Zen Dojo**: an offline, open-source engineering course and practice tool. This release is the biggest so far. You can run code against hidden tests, learn low-level design from complete Java projects, make the app look the way you want, and add your own lessons and problems without touching the code.

### Your data is safe when you update
The app keeps using the same data folder it always had (`HabitManager` in your app-data folder), so installing 0.4.0 over an older version keeps everything. Before the first start of a new version the app also copies your database to `backups/`. The installer file is now called `ZenDojo-<version>-<os>-<arch>`. Your existing shortcut may keep the old name and icon until you recreate it.

### Run your code, like LeetCode
- **81 problems you can run** (77 from the roadmap, 4 from CSES) in **C++, Java and JavaScript**. Each has a statement, constraints, examples, hints and a solution. Write only the function; the starter code does the rest.
- **Results you can trust:** every case shows its input, expected answer and your output. A crash or a hang on one case doesn't hide the others. What your code prints appears in its own Console section, only when something was printed. Common mistakes (out-of-range vector access, wrong output type) get a plain-language explanation.
- **Speed and memory checks:** every problem also runs large inputs (the biggest sizes the limits allow, sorted, reversed, all equal, long chains, answers that need 64 bits, very deep recursion). Each runs on its own with a time limit and a 256 MB memory limit, so a slow or wasteful solution is reported as "Right answer, but too slow" or "Memory limit exceeded".
- **Accepted solutions save themselves** with the problem; your notes are never touched.
- **CSES problems live in the same list** as the rest, with your own notes and solution and no LeetCode-only tabs.
- **A problem screen like LeetCode's:** Problem, Code and Results panes. Drag a divider to resize, drag a pane title to swap panes, maximise one, or pick a layout (Classic, Columns, Stacked, Code focus). On a problem page the sidebar becomes a slim bar with a slide-out menu (Ctrl+B) so the problem and editor get the room, and the window itself never scrolls: each pane scrolls on its own. Back and forward stay in the bar.

### Learn
- **Courses on the Learn page:** System design, Low-level design, Core CS, DSA patterns and the Reading list are cards with progress, what's left, what's due, a next step and a favourite star. A "Continue where you left off" card remembers where you were.
- **LLD as real Java projects** (compiled and run with JDK 17 in the test suite, each with a long walkthrough and class and sequence diagrams): parking lot, elevator, vending machine, LRU cache and rate limiter, URL shortener, logger and notification system.
- **DSA pattern articles** with C++ templates for prefix sums, Kadane, intervals, cyclic sort, string matching, matrix, binary search, quickselect, merge-sort counting, fast and slow pointers, list reversal, monotonic stack and deque, parsing with stacks, top-k and two heaps, and LRU/LFU. Lessons also have Mermaid diagrams.
- **Lesson sidebar tracker:** "On this page" highlights the section you are in, slides a marker to it, and shows how far down you are.

### Make it yours (Profile > Settings)
- **Appearance:** Light, Dark or System; five accent colours that look the same in light and dark; seven whole-UI styles (Classic, Paper, Ocean, Terminal, Sage, Dusk, Ember) with measured contrast; reading fonts (Lexend, Atkinson Hyperlegible, Serif).
- **Your own colours:** pick any accent and your own light and dark palettes, with a warning when text would be hard to read.
- **Your own font:** type the name of an installed font or upload a font file (kept in this app only).
- **Profile:** a display name and a profile picture.
- **Focus reading:** optional bold word starts (Subtle or Strong) for reading areas.
- **Animations:** Auto, On or Off. Off removes every animation and transition.
- **Game features are off by default:** XP, levels, streaks and badges are hidden until you turn them on. Your progress is still tracked underneath.

### Add content without changing the code (content packs)
- A **content pack** is one JSON file with new lessons and Run-button problems. Paste it, choose a file, or give a web address in **Profile > Settings > Content**; "Check only" lists every mistake in plain words before you install. A pack becomes a course in Learn with progress, and its problems open in the same editor. Passing every test marks the problem done.
- The format, an example file and a ready-made prompt for another AI (to turn any source into a pack) are in `docs/content-packs.md` and `docs/examples/sample-pack.json`.
- Imported problems are judged on their examples and tests; the large-input checks are only for the built-in ones.

### Everyday use
- **A better sidebar:** a logo mark, a soft highlight with an accent bar for the page you are on, and your profile picture and name at the bottom.
- **Whole cards and rows are clickable**, with a pointer, a hover lift and one clear keyboard focus ring. Every button, link and dropdown now shows a pointer.
- **Desktop navigation:** back and forward with Alt+Left/Right, the mouse side buttons, a two-finger swipe, the Go menu and on-screen buttons.
- **Streak freeze and weekly review:** one freeze per week covers a missed day; a weekly review shows the week next to the one before, with a place for your own reflection.
- **LeetCode time:** the browser extension reports time spent on a problem page. The extension now has the new icon and name.
- **A slimmer Today:** a progress bar beside "Up next", a "Keep learning" suggestion when you are done, and a short staggered list.

### Notes
- Imported packs and their progress are part of backups. Appearance choices, your profile picture and any font you add are saved in this app window only and are not part of a backup.
- About 105 roadmap problems and most of CSES do not have a Run button yet; they open as before with notes and the LeetCode link.
- macOS builds are not signed with a Developer ID (see the README for the one-time step). Windows and Linux AppImage update themselves.
