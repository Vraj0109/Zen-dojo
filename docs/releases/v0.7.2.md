## Zen Dojo 0.7.2: Python, solutions in Java and Python, a plan that follows your progress, downloadable tools and an optional local AI

### Python in the code runner
- Pick Python next to C++, Java and JavaScript on any problem with a Run button. Every problem has a Python starter, your Python code is saved per problem, and trees, linked lists and "design a class" problems work.
- Python gets longer time limits than C++, the way judging sites do: each case has its own limit and the cases together share a bigger budget.
- JavaScript no longer needs Node installed on your computer.

### Java and Python solutions for every problem
- All 486 problems now show reference solutions in C++, Java and Python as tabs. Each file was run against the problem's tests before it was added.
- Three wrong expected answers were fixed (`cses-nim-game-i`, `c-cf-148a`, `cses-palindrome-queries`).

### A plan that follows what you finished
- Your plan week no longer moves with the calendar. Miss a week and you are still on week 3 with 14 weeks left. Today shows today's tasks from your current plan week.
- A new Backlog page lists tasks planned for earlier days, with their dates, and the rest of the week to work ahead. Finish the whole week in one sitting and the plan moves to the next week by itself. "Skip the rest of this week" is there if you want it.
- The old "Shift schedule" buttons are gone.

### Tools for running code
- Profile, Settings, Tools for running code shows what is installed and the exact command to fix what is missing.
- On the desktop app, "Set up" can download Java, Python and (on Windows) a C++ compiler into the app's own folder. It shows the source and size first, checks every file against a known hash, needs no admin rights, and Remove deletes it all.

### Local AI helper (optional, off by default)
- If you install Ollama, Settings can suggest a model that fits your memory or graphics card. Problem pages then get an "Ask local AI" panel to explain a hint, review your code or explain the solution. Everything stays on your computer, and the settings do not sync.

### Smaller fixes
- The Today page no longer scrolls sideways, course pages with uneven sections no longer leave a big gap, and the account arrow points the right way.
- The README and the release page now explain the first-launch warnings on each system.
