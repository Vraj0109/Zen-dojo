## Zen Dojo 0.9.0: sign-in and sync now go through the website, plus Help and more things that sync

### Sign-in and sync moved
- Sign-in with GitHub and cloud sync now go through the Zen Dojo website (`/hub` on https://zen-dojo-lovat.vercel.app) instead of a separate Cloudflare service. Your cloud copy was moved over with the same counts (solved problems, tasks, notes, settings, runs).
- **After updating you may be asked to sign in once more.** Your local progress is untouched. If the cloud copy and this computer differ, sync merges them as before (the newer change wins for the same item).
- The desktop app and `pnpm dev` use the website's address by default. Set `HUB_URL` if you run your own copy.

### More of your progress syncs
- The reading list (progress and your own links), the stuck list and boss fights now sync between devices, with the same first-link upload as the other tables.

### Help and FAQ
- New **Help and FAQ** page (`/help`, also linked from the Profile page and in `docs/faq.md`): about 60 answers on installing and updating on each system, the macOS "Apple could not verify" message and the C++ header error, Windows blocking freshly built programs, compilers and the tool manager, AI models and bring-your-own-key, accounts, sync and what becomes public, with search and category filters.
- It also explains plainly that the MIT licence on GitHub is not a code-signing certificate: it does nothing for Windows SmartScreen or macOS Gatekeeper.

### Public profile (optional)
- On the Portfolio page you can make your profile public. It publishes only the numbers on that page (name, level, streaks, solved counts, courses, activity, badges), never notes or code, and turning it off deletes the published copy.

### Smaller things
- Admins get a lesson editor at `/admin/study` (overview, explanations, interview questions and common mistakes; saved edits show without a new release).
- The CSES "grid path description" Python solution is faster.
- Reader mode for small screens, an Ask AI sheet and an installable web app apply to the website; the desktop app is unchanged by them.

### Under the hood
- The sync service code now runs inside the website on Vercel with Turso as its database. The old Cloudflare Worker stays up for older desktop versions until you have updated, then it is switched off.
