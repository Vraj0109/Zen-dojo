Consistent hashing

Spread keys across servers so adding or removing one moves only a small share of keys.

The problem with modulo

With hash(key) % n, going from 4 to 5 servers moves about 80% of the keys. Every cache misses at once and the database takes the full load.

Interview tip. Mention virtual nodes early: 100 to 200 per server evens out the load.

The ring

Place servers and keys on the same circle of hash values. Each key belongs to the first server clockwise from it.
