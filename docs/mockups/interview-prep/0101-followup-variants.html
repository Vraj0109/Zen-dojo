OnlineVariant 2 of 4

Now the numbers arrive one at a time, and after each one I want to know whether some pair so far adds up to the target.

What changes

You cannot rescan the whole array after every arrival; that would be quadratic overall.

Approach

Keep a hash set of the values seen so far. For each new value x, check whether target - x is in the set, then add x.

Cost

O(1) per arrival, O(n) space

Trap

Adding x before the check makes a single value pair with itself.
