Longest run after replacements

Medium

Given a string and k, return the length of the longest substring you can make of one repeated letter after at most k replacements.

class Solution {
    public int characterReplacement(String s, int k) {
        int[] cnt = new int[26];
        int best = 0, lo = 0, maxf = 0;
        for (int hi = 0; hi < s.length(); hi++) {
            maxf = Math.max(maxf, ++cnt[s.charAt(hi) - 'A']);
            while (hi - lo + 1 - maxf > k) cnt[s.charAt(lo++) - 'A']--;
            best = Math.max(best, hi - lo + 1);
        }
        return best;
    }
}

This method should return, for each day, the number of days until a warmer temperature, or 0 if there is none.

int[] daysToWarmer(int[] t) {
    int[] res = new int[t.length];
    Deque<Integer> st = new ArrayDeque<>();
    for (int i = 0; i < t.length; i++) {
        while (!st.isEmpty() && t[i] >= t[st.peek()]) {
            int j = st.pop();
            res[j] = i - j;
        }
        st.push(i);
    }
    return res;
}
