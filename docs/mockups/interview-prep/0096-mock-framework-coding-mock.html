Longest Substring Without Repeating Characters

Code: write the full solution, then run the examples. Keep talking while you type.

Given a string s, return the length of the longest substring that has no repeated character.

1 <= s.length <= 50,000. Characters are ASCII.

Input: "abcabcbb"
Output: 3  (the substring "abc")

No Hints, Solution or Ask AI tabs in a mock.

Java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[128];
        int best = 0, left = 0;
        for (int right = 0; right < s.length(); right++) {
            left = Math.max(left, last[s.charAt(right)]);
            best = Math.max(best, right - left + 1);
            last[s.charAt(right)] = right + 1;
        }
        return best;
    }
}
