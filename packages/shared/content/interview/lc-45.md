## Clarify first

- Is the destination always reachable? Yes, constraints guarantee that you can always reach the last position.
- What if the array length is 1? You are already at the destination, so 0 jumps are needed.
- Can we jump beyond the last index? Yes, reaching or jumping past the last index satisfies the goal.
- What are the constraints on array length and values? Length is between 1 and 10,000, and `nums[i]` is between 0 and 1,000.

## Examples to say out loud

- Standard array: `nums = [2, 3, 1, 1, 4]`.
  - From index 0, you can jump to 1 or 2.
  - Jumping to index 1 gives maximum reach `1 + 3 = 4`, which reaches the end.
  - Total minimum jumps = 2.
- Single large jump: `nums = [10, 1, 1, 1, 1]`.
  - From index 0, you can jump directly past the end in 1 jump. Total jumps = 1.
- Unit steps: `nums = [1, 1, 1, 1]`.
  - Each step advances by 1. Total jumps = 3.

## Brute force

A brute-force dynamic programming approach defines `dp[i]` as the minimum jumps required to reach index `i`. For each index `i`, we initialize `dp[i] = infinity`, and for every earlier index `j < i`, if `j + nums[j] >= i`, we transition `dp[i] = min(dp[i], dp[j] + 1)`. Because this checks all pairs `(j, i)`, it takes `O(n^2)` time. With `n = 10,000`, this requires `10^8` operations, which can be optimized to linear time.

## The key observation

This problem is breadth-first search in disguise. Each "jump level" `k` covers a contiguous interval of indices `[curStart, curEnd]`. To determine the boundary of the next level `k + 1`, we simply find the maximum index `farthest = max(i + nums[i])` reachable from any position `i` within the current range. When our linear scan reaches `curEnd`, we must take another jump, updating `curEnd = farthest`.

## Optimal approach

1. Let `n = nums.length`. If `n <= 1`, return 0.
2. Initialize `jumps = 0`, `curEnd = 0` (boundary of current jump range), and `farthest = 0` (furthest index reachable).
3. Iterate `i` from 0 to `n - 2`:
   a. Update `farthest = max(farthest, i + nums[i])`.
   b. If `i == curEnd`:
      i. Increment `jumps`.
      ii. Set `curEnd = farthest`.
      iii. If `curEnd >= n - 1`, break early.
4. Return `jumps`.

Complexity:
- Time: `O(n)` because we iterate through the array of length `n` once, doing constant work per index.
- Space: `O(1)` auxiliary space as we only maintain three scalar integer variables.

## Code walkthrough

In the reference implementation:
- `int jumps = 0, curEnd = 0, farthest = 0, n = (int)nums.size();`: tracks jump count, current BFS level boundary, and next level horizon.
- `for (int i = 0; i < n - 1; i++)`: loops strictly up to `n - 2` because standing on `n - 1` requires no further jump.
- `farthest = max(farthest, i + nums[i]);`: extends the reachable frontier of the subsequent jump.
- `if (i == curEnd)`: signifies we have exhausted all options within the current jump allocation and must trigger the next jump.
- `jumps++; curEnd = farthest;`: increments jump count and sets new range endpoint.

## Test it out loud

- `nums = [2, 3, 1, 1, 4]`:
  - `i = 0`: `farthest = max(0, 0 + 2) = 2`. `i == curEnd (0)` -> `jumps = 1`, `curEnd = 2`.
  - `i = 1`: `farthest = max(2, 1 + 3) = 4`.
  - `i = 2`: `farthest = max(4, 2 + 1) = 4`. `i == curEnd (2)` -> `jumps = 2`, `curEnd = 4`.
  - Loop ends at `i = 3` (or breaks early). Returns 2.
- `nums = [2, 1]`:
  - `i = 0`: `farthest = 2`. `i == curEnd` -> `jumps = 1, curEnd = 2`.
  - Loop terminates. Returns 1.
- `nums = [0]`: loop does not execute (`n - 1 = 0`), returns 0.

## Follow-ups

- What if the last index is not guaranteed to be reachable?
  Add the check `if (i > farthest) return -1;` from Jump Game I.
- Can we reconstruct the path of indices jumped?
  Record the index `best_i` that produced `farthest` during each level, jumping from one chosen index to the next.

## Common mistakes

- Looping up to `n - 1` instead of `n - 2`, which mistakenly triggers an extra jump when `curEnd` lands on `n - 1`.
- Using `O(n^2)` dynamic programming instead of the greedy BFS level approach.
- Not handling the single-element edge case where 0 jumps are needed.
