## Clarify first

- Is division allowed? No, the problem explicitly forbids using division.
- Can elements be 0 or negative? Yes, values range from -30 to 30.
- What if there are multiple zeros? If there are two or more zeros, all output values are 0. If there is exactly one zero, all outputs are 0 except at the zero's position.
- Will any product exceed 32-bit integer limits? The problem guarantees that any prefix or suffix product fits within a standard 32-bit signed integer.
- Does the output array count toward the auxiliary space complexity? As standard in interview conventions, the returned array does not count toward auxiliary space.

## Examples to say out loud

- Normal positive array: `nums = [1, 2, 3, 4]`.
  - Prefix products before each index: `[1, 1, 2, 6]`.
  - Suffix products after each index: `[24, 12, 4, 1]`.
  - Result: `[24, 12, 8, 6]`.
- Single zero: `nums = [-1, 1, 0, -3, 3]`.
  - All indices except index 2 include the 0 in their product, resulting in 0.
  - At index 2, the product of other elements is `(-1) * 1 * (-3) * 3 = 9`. Result: `[0, 0, 9, 0, 0]`.
- Two elements edge case: `nums = [2, 3]`. Output is `[3, 2]`.

## Brute force

A brute-force solution calculates each `answer[i]` by running an inner loop over all `j != i` from `0` to `n - 1`, multiplying `nums[j]`. For `n` elements, computing the product of `n - 1` terms takes `O(n)` time per element, leading to `O(n^2)` total time. Given `n = 100,000`, `n^2 = 10^{10}` operations, which times out.

## The key observation

For any element at index `i`, `answer[i]` is simply the product of all elements to its left (`nums[0..i-1]`) multiplied by the product of all elements to its right (`nums[i+1..n-1]`). We can compute prefix products in a left-to-right pass directly into `answer`, and then accumulate suffix products in a right-to-left pass using a single running scalar variable.

## Optimal approach

1. Allocate the output array `ans` of length `n`.
2. First pass (left-to-right):
   a. Initialize `left = 1`.
   b. For `i` from 0 to `n - 1`: set `ans[i] = left`, then multiply `left *= nums[i]`.
3. Second pass (right-to-left):
   a. Initialize `right = 1`.
   b. For `i` from `n - 1` down to 0: multiply `ans[i] *= right`, then multiply `right *= nums[i]`.
4. Return `ans`.

Complexity:
- Time: `O(n)` because we traverse the array of length `n` exactly twice with `O(1)` operations per step.
- Space: `O(1)` auxiliary space beyond the required `O(n)` return array.

## Code walkthrough

In the reference implementation:
- `vector<int> ans(n, 1);`: allocates the output buffer of size `n`.
- `int left = 1; for (int i = 0; i < n; i++) { ans[i] = left; left *= nums[i]; }`: populates each slot with the cumulative product of elements strictly preceding it.
- `int right = 1; for (int i = n - 1; i >= 0; i--) { ans[i] *= right; right *= nums[i]; }`: folds in the cumulative product of elements strictly following it.
- `return ans;`: returns the combined prefix-suffix product array.

## Test it out loud

- `nums = [2, 3]`:
  - Pass 1:
    - `i = 0`: `ans[0] = 1`, `left = 2`.
    - `i = 1`: `ans[1] = 2`, `left = 6`.
  - Pass 2:
    - `i = 1`: `ans[1] *= 1` -> 2, `right = 3`.
    - `i = 0`: `ans[0] *= 3` -> 3, `right = 6`.
  - Output: `[3, 2]`.
- `nums = [5, 0, 2]`:
  - Pass 1: `ans` becomes `[1, 5, 0]`.
  - Pass 2: `right` starts at 1.
    - `i = 2`: `ans[2] = 0 * 1 = 0`, `right = 2`.
    - `i = 1`: `ans[1] = 5 * 2 = 10`, `right = 2 * 0 = 0`.
    - `i = 0`: `ans[0] = 1 * 0 = 0`, `right = 0`.
  - Output: `[0, 10, 0]`.

## Follow-ups

- What if division was allowed?
  Compute the total product of non-zero elements and count zeros: if zero count > 1, all 0; if zero count == 1, only the zero index gets total product; if zero count == 0, `ans[i] = total / nums[i]`.
- What if the array could not fit in 32-bit integers?
  Work with 64-bit integers or modulo arithmetic depending on requirements.

## Common mistakes

- Trying to compute prefix and suffix products into two separate auxiliary arrays of size `n`, taking `O(n)` extra memory instead of `O(1)`.
- Forgetting to exclude `nums[i]` from `ans[i]`, e.g., updating `left *= nums[i]` before setting `ans[i] = left`.
- Attempting division by zero when handling arrays containing zeros.
