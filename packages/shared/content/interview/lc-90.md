## Clarify first
- Can the input array contain duplicates? Yes, `nums` may contain duplicate elements.
- How are duplicate subsets defined? Two subsets are identical if they contain the same elements with the same frequencies, regardless of order.
- In what order should the subsets be returned? Any order is acceptable.
- Can subsets be empty? Yes, the empty set `[]` is always a valid subset and must be included.

## Examples to say out loud
- Standard duplicate case: `nums = [1, 2, 2]`.
  - Distinct subsets: `[[], [1], [1, 2], [1, 2, 2], [2], [2, 2]]`.
  - Notice `[2]` is generated once, not twice. Total: 6 subsets.
- Identical elements: `nums = [1, 1]`.
  - Subsets: `[[], [1], [1, 1]]`.
- Distinct elements: `nums = [0]`.
  - Subsets: `[[], [0]]`.

## Brute force
A brute force approach generates all `2^n` subsets using standard backtracking without duplicate pruning, sorts each subset, inserts them into a hash set of lists, and then converts the hash set to a list. While correct, this creates duplicate subsets and incurs overhead from string/vector hashing and sorting. We can prune duplicates directly during backtracking by sorting first.

## The key observation
If we sort `nums` in non-decreasing order, all duplicate elements will be adjacent.
When building a subset via recursive backtracking:
- At the current recursion level, we choose which element to append next from index `i` in range `[start, n - 1]`.
- If `nums[i] == nums[i - 1]` and `i > start`, it means that we already explored all subsets that include a branch starting with this duplicate value at the current position.
- Therefore, skipping when `i > start && nums[i] == nums[i - 1]` completely eliminates redundant branches without missing any valid combinations.

## Optimal approach
1. Sort `nums` in non-decreasing order.
2. Initialize an empty result list `out` and a path list `cur`.
3. Define a recursive helper `go(start)`:
   - Append a copy of `cur` to `out` (every prefix state forms a valid subset).
   - For `i` from `start` to `nums.size() - 1`:
     - If `i > start` and `nums[i] == nums[i - 1]`: continue (skip duplicate choice at this tree level).
     - Add `nums[i]` to `cur`.
     - Recurse: `go(i + 1)`.
     - Backtrack: remove `nums[i]` from `cur`.
4. Call `go(0)` and return `out`.

Complexity:
- Time complexity: O(n * 2^n) because there are at most 2^n subsets, and copying each subset to the output list takes O(n) time.
- Space complexity: O(n) auxiliary space for the recursion call stack and `cur` list (excluding the output container).

## Code walkthrough
- `sort(nums.begin(), nums.end())`: Groups identical elements together to facilitate duplicate detection.
- `out.push_back(cur)`: Commits the current subset at the start of each recursive call.
- `if (i > start && a[i] == a[i - 1]) continue`: Crucial duplicate-skipping condition. It ensures identical elements are chosen only from left to right in contiguous fashion.
- `cur.push_back(a[i]); go(a, i + 1, ...); cur.pop_back()`: Standard choose-explore-unchoose backtracking pattern.

## Test it out loud
- Test `nums = [1, 2, 2]`:
  - `start = 0`: adds `[]`.
  - Chooses 1: adds `[1]`.
    - Chooses first 2: adds `[1, 2]`.
      - Chooses second 2: adds `[1, 2, 2]`.
    - Skips second 2 because `i = 2 > start (1)` and `nums[2] == nums[1]`.
  - Backtracks to root.
  - Chooses first 2: adds `[2]`.
    - Chooses second 2: adds `[2, 2]`.
  - Skips second 2 at root level because `i = 2 > start (0)` and `nums[2] == nums[1]`.
  - Output: `[], [1], [1, 2], [1, 2, 2], [2], [2, 2]`. Correct.

## Follow-ups
- How does Subsets II differ from Subsets I? Subsets I has distinct elements so no skipping is needed. Subsets II requires sorting and skipping duplicate sibling branches with `i > start && nums[i] == nums[i - 1]`.
- Can this be done iteratively? Yes, sort `nums`. When adding a duplicate number, only append it to subsets generated in the immediately preceding step rather than all existing subsets.

## Common mistakes
- Using `i > 0` instead of `i > start` for the duplicate check, which mistakenly prunes valid subsets containing multiple identical elements (e.g. `[2, 2]`).
- Forgetting to sort `nums` before starting the backtracking recursion.
