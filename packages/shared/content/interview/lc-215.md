## Clarify first

- Does `k` refer to the k-th distinct element or the k-th element in sorted order? The problem states duplicates count separately: the k-th largest element in sorted order.
- What if `k = 1`? The answer is simply the maximum element in the array.
- Can numbers be negative? Yes, values range from -10,000 to 10,000.
- What are the constraints on array length? Length is between 1 and 100,000, and `1 <= k <= nums.length`.

## Examples to say out loud

- Array with duplicates: `nums = [3, 2, 1, 5, 6, 4]`, `k = 2`.
  - Sorted descending: `[6, 5, 4, 3, 2, 1]`.
  - The 2nd largest element is 5.
- Repeated maximum: `nums = [3, 2, 3, 1, 2, 4, 5, 5, 6]`, `k = 4`.
  - Sorted descending: `[6, 5, 5, 4, 3, 3, 2, 2, 1]`.
  - The 4th largest element is 4.
- Negative numbers: `nums = [-1, -1]`, `k = 2`. Returns -1.

## Brute force

A brute-force solution sorts the entire array of `n` elements in non-decreasing order using an efficient comparison sort (like introsort) and returns `nums[n - k]`. This takes `O(n log n)` time and `O(1)` or `O(log n)` auxiliary space. For `n = 100,000`, sorting the entire array does unnecessary work because we do not need the relative order among the remaining `n - k` elements.

## The key observation

To find the k-th largest element, we only need to maintain the top `k` largest elements seen so far. A min-heap capped at size `k` holds these `k` largest elements, where the smallest among them sits directly at the root (`heap.top()`). Whenever the heap size exceeds `k`, ejecting the minimum element preserves the invariant that the heap contains the `k` largest numbers, with the k-th largest readily accessible in `O(1)` at the top.

## Optimal approach

1. Initialize a min-heap (priority queue with greater comparator).
2. For each number `x` in `nums`:
   a. Push `x` into the min-heap.
   b. If the heap size exceeds `k`, pop the top (minimum) element from the heap.
3. After processing all elements, the heap contains the `k` largest elements from the array.
4. Return `heap.top()`.

Complexity:
- Time: `O(n log k)` because each of the `n` elements is pushed into a heap of size at most `k + 1`, requiring `O(log k)` per insertion/deletion.
- Space: `O(k)` auxiliary space for the heap holding at most `k + 1` elements.

## Code walkthrough

In the reference implementation:
- `priority_queue<int, vector<int>, greater<int>> heap;`: declares a min-heap structure.
- `for (int x : nums)`: streams through every number in the input list.
- `heap.push(x);`: inserts the current value into the heap.
- `if ((int)heap.size() > k) heap.pop();`: immediately discards the smallest element once the size threshold is crossed.
- `return heap.top();`: yields the smallest of the top `k` values, which is the k-th largest element overall.

## Test it out loud

- `nums = [3, 2, 1, 5, 6, 4], k = 2`:
  - `x = 3`: heap `[3]`.
  - `x = 2`: heap `[2, 3]`.
  - `x = 1`: heap `[1, 2, 3]` -> pop 1, heap `[2, 3]`.
  - `x = 5`: heap `[2, 3, 5]` -> pop 2, heap `[3, 5]`.
  - `x = 6`: heap `[3, 5, 6]` -> pop 3, heap `[5, 6]`.
  - `x = 4`: heap `[4, 5, 6]` -> pop 4, heap `[5, 6]`.
  - Return `heap.top() = 5`.
- `nums = [1], k = 1`: heap `[1]`, returns 1.

## Follow-ups

- Can we achieve `O(n)` average time?
  Yes, Quickselect (Hoare's selection algorithm) partitions the array around a random pivot and recurses into only the half containing index `n - k`. This runs in `O(n)` expected time and `O(1)` auxiliary space, though worst-case is `O(n^2)` without median-of-medians.
- What if numbers arrive in an infinite stream?
  The min-heap approach of size `k` is ideal for streaming data because it requires only `O(k)` memory and processes each streaming item in `O(log k)` time.

## Common mistakes

- Using a max-heap of all `n` elements, taking `O(n log n)` time and `O(n)` space instead of a min-heap of size `k`.
- Removing duplicates before finding the k-th largest, which violates the requirement that duplicate values count separately.
- Forgetting that the min-heap top gives the *smallest* of the `k` largest elements (which is the k-th largest overall).
