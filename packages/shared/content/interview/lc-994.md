## Clarify first
- What do the values in the grid represent? 0 represents an empty cell, 1 represents a fresh orange, and 2 represents a rotten orange.
- In what directions does rot spread? Vertically and horizontally into the 4 adjacent neighbors (up, down, left, right).
- What should be returned if all oranges are already rotten or if no fresh oranges exist? Return 0 minutes immediately.
- What should be returned if some fresh orange can never be reached? Return -1.

## Examples to say out loud
- Standard progression: `grid = [[2,1,1],[1,1,0],[0,1,1]]`.
  - Minute 0: rotten at (0, 0), fresh count = 6.
  - Minute 1: (0, 1) and (1, 0) rot; fresh = 4.
  - Minute 2: (0, 2) and (1, 1) rot; fresh = 2.
  - Minute 3: (2, 1) rots; fresh = 1.
  - Minute 4: (2, 2) rots; fresh = 0.
  - Returns 4.
- Disconnected case: `[[2,1,1],[0,1,1],[1,0,1]]`. Cell (2, 0) is surrounded by empty cells and cannot rot. Returns -1.
- No fresh oranges: `[[0,2]]`. Returns 0.

## Brute force
A brute force approach simulates the rotting process round by round. In each minute, it scans the entire grid, marks which fresh oranges are adjacent to currently rotten oranges, converts them to rotten, and repeats until no new oranges rot. In the worst case (a snake path of size `r * c`), this takes `O((r * c)^2)` time. We can achieve optimal O(r * c) time using a multi-source Breadth-First Search.

## The key observation
Rot spreads simultaneously outward from all initially rotten oranges, identical to expanding wavefronts from multiple sources in an unweighted graph.
By placing all initially rotten orange coordinates into a BFS queue at minute 0 and advancing the queue level-by-level (where one level corresponds to exactly one minute), every fresh orange is reached at the earliest possible minute. Tracking the remaining count of fresh oranges allows checking for unreachable oranges in O(1) at termination.

## Optimal approach
1. Scan the grid:
   - Push all coordinates with `grid[i][j] == 2` into a FIFO queue `q`.
   - Count the total number of fresh oranges `fresh` (`grid[i][j] == 1`).
2. If `fresh == 0`, return 0 immediately.
3. Initialize `minutes = 0`.
4. While `q` is not empty and `fresh > 0`:
   - Determine `sz = q.size()` (current minute wavefront).
   - For each of the `sz` rotten oranges:
     - Pop `(x, y)` and inspect its 4 cardinal neighbors `(nx, ny)`.
     - If `(nx, ny)` is within grid bounds and `grid[nx][ny] == 1`:
       - Mark `grid[nx][ny] = 2`.
       - Decrement `fresh`.
       - Push `(nx, ny)` into `q`.
   - Increment `minutes`.
5. Return `fresh == 0 ? minutes : -1`.

Complexity:
- Time complexity: O(r * c) where r is rows and c is columns, as each cell is visited and added to the queue at most once.
- Space complexity: O(r * c) auxiliary space for the BFS queue storing at most r * c coordinates.

## Code walkthrough
- Initial scan: Gathers all starting multi-sources into `q` and tallies `fresh`.
- `while (!q.empty() && fresh > 0)`: Ensures we only increment `minutes` if there were actually fresh oranges converted during the round.
- `int sz = (int)q.size()`: Processes the queue level by level, ensuring all rotten cells in the current minute infect their neighbors simultaneously.
- `grid[nx][ny] = 2; fresh--; q.push({nx, ny})`: Infects adjacent fresh oranges in place, preventing duplicate visits.
- Returns `fresh == 0 ? minutes : -1`.

## Test it out loud
- Test `[[0]]`:
  - `q` is empty, `fresh = 0`. Loop does not run. Returns 0. Correct.
- Test `[[1]]`:
  - `q` is empty, `fresh = 1`. Loop does not run. `fresh != 0`, returns -1. Correct.
- Test `[[2]]`:
  - `q = [(0, 0)]`, `fresh = 0`. Loop condition `fresh > 0` is false. Returns 0. Correct.
- Test `[[1, 2]]`:
  - `q = [(0, 1)]`, `fresh = 1`.
  - Minute 1: infects (0, 0), `fresh = 0`. Loop terminates. Returns 1. Correct.

## Follow-ups
- What if rot had different infection delays per cell? Use Dijkstra's algorithm with a priority queue rather than standard FIFO BFS.
- How can we solve this if the grid cannot be modified? Use a `dist[r][c]` 2D array or a visited hash set to record infected times.

## Common mistakes
- Incrementing `minutes` after the queue becomes empty even when no fresh oranges were infected in that iteration.
- Using a single-source BFS from each rotten orange separately, which leads to redundant explorations.
- Forgetting to check if any fresh oranges remain disconnected at the end.
