## Clarify first

- What happens to the boundaries when a balloon is burst? The adjacent remaining balloons become immediate neighbors.
- What if a balloon bursts at the edge of the array? Balloons outside the array boundaries are treated as virtual balloons with fixed value 1.
- Can `nums[i]` be 0? Yes, numbers range between 0 and 100.
- What are the constraints on array length? Length is between 1 and 300.

## Examples to say out loud

- Strategic order: `nums = [3, 1, 5, 8]`.
  - Padded array: `[1, 3, 1, 5, 8, 1]`.
  - Burst 1: coins = `3 * 1 * 5 = 15`. Remaining: `[3, 5, 8]`.
  - Burst 5: coins = `3 * 5 * 8 = 120`. Remaining: `[3, 8]`.
  - Burst 3: coins = `1 * 3 * 8 = 24`. Remaining: `[8]`.
  - Burst 8: coins = `1 * 8 * 1 = 8`.
  - Total coins = `15 + 120 + 24 + 8 = 167`.
- Single balloon: `nums = [5]`. Coins = `1 * 5 * 1 = 5`.
- Two balloons: `nums = [1, 5]`. Burst 1 first (`1 * 1 * 5 = 5`), then 5 (`1 * 5 * 1 = 5`), total = 10.

## Brute force

A brute-force solution tries every possible sequence of bursting balloons. For `n` balloons, there are `n!` burst orders. For each step, recalculating neighbors and recursing takes `O(n!)` factorial time. For `n = 300`, `300!` is vastly beyond computable limits.

## The key observation

Thinking forward ("which balloon to burst *first*?") makes subproblems dependent, because bursting balloon `k` brings its left and right neighbors together, coupling the two halves.
Instead, **think backward**: **Which balloon is burst *last* in the range `(i, j)`?**
If balloon `k \in (i, j)` is the very last balloon to be burst inside the open interval `(i, j)`, then:
1. Every other balloon in `(i, k)` and `(k, j)` has already been burst.
2. Therefore, when balloon `k` bursts, its remaining neighbors must be the boundary balloons `a[i]` and `a[j]`!
3. The coins earned from bursting `k` last are `a[i] * a[k] * a[j]`.
4. The subproblems `(i, k)` and `(k, j)` are now completely independent!
Hence: `dp[i][j] = \max_{k \in (i, j)} (dp[i][k] + dp[k][j] + a[i] * a[k] * a[j])`.

## Optimal approach

1. Pad `nums` with boundary 1s: create array `a = [1, nums[0], ..., nums[n-1], 1]` of size `n + 2`.
2. Allocate a 2D table `dp` of size `(n + 2) \times (n + 2)` filled with zeros.
3. Iterate interval span `len` from 2 to `n + 1`:
   - Iterate left boundary `i` from 0 up to `n + 1 - len`:
     - Let `j = i + len`.
     - For each candidate last-burst balloon `k` from `i + 1` to `j - 1`:
       - `dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j] + a[i] * a[k] * a[j])`.
4. Return `dp[0][n + 1]`.

Complexity:
- Time: `O(n^3)` because there are `O(n^2)` sub-intervals `(i, j)`, and evaluating each interval iterates over up to `n` choices for `k`. For `n = 300`, `300^3 / 6 \approx 4.5 \times 10^6` operations, which executes in under 20 milliseconds.
- Space: `O(n^2)` auxiliary space for the `(n + 2) \times (n + 2)` dynamic programming table.

## Code walkthrough

In the reference implementation:
- `vector<int> a = {1}; for (int x : nums) a.push_back(x); a.push_back(1);`: pads the array with virtual 1-balloons on both sides.
- `vector<vector<int>> dp(n, vector<int>(n, 0));`: holds the maximum coins collected by bursting all balloons strictly between index `i` and index `j`.
- `for (int len = 2; len < n; len++)`: iterates in order of increasing interval length to ensure sub-intervals are computed first.
- `int j = i + len;`: fixes the right boundary of the open interval.
- `dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j] + a[i] * a[k] * a[j]);`: merges the optimal independent left and right halves with the coin reward of bursting `k` last.
- `return dp[0][n - 1];`: yields the maximum coins for the entire padded range.

## Test it out loud

- `nums = [3, 1, 5, 8]`:
  - `a = [1, 3, 1, 5, 8, 1]`, `n = 6`.
  - `len = 2` (intervals of length 1 balloon inside):
    - `dp[0][2]` (balloon 3): `1 * 3 * 1 = 3`.
    - `dp[1][3]` (balloon 1): `3 * 1 * 5 = 15`.
    - `dp[2][4]` (balloon 5): `1 * 5 * 8 = 40`.
    - `dp[3][5]` (balloon 8): `5 * 8 * 1 = 40`.
  - As `len` increases, larger intervals combine smaller ones.
  - Finally, `dp[0][5]` reaches 167 (bursting 8 last: `dp[0][4] + dp[4][5] + 1 * 8 * 1`). Result: 167.
- `nums = [5]`: `a = [1, 5, 1]`, `len = 2`: `k = 1`, `dp[0][2] = 1 * 5 * 1 = 5`. Result: 5.

## Follow-ups

- How does this relate to Matrix Chain Multiplication?
  Identical structural interval DP: both split intervals `(i, j)` at partition `k` with cost depending on the boundaries and `k`.
- What if balloons are arranged in a circular ring?
  Duplicate the array to length `2 * n` and find the maximum over all subsegments of length `n`.

## Common mistakes

- Trying to select the first balloon to burst, which causes left and right subproblems to share variable boundaries and breaks optimal substructure.
- Forgetting to pad both ends with 1s, which leads to index boundary errors.
- Iterating loops in wrong order (must loop over interval length `len` first, not `i` and `j` randomly).
