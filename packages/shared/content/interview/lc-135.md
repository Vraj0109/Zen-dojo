## Clarify first
- Are all ratings non-negative integers? Yes, ratings are non-negative.
- Does each child require at least one candy? Yes, every child receives at least one candy.
- How do equal ratings behave? If two adjacent children have equal ratings, the rule does not require either to have more candies than the other.
- Can we return the total minimum candy count directly as an integer? Yes.

## Examples to say out loud
- Consider `ratings = [1, 0, 2]`:
  - Child 1 has rating 0 (valley) and receives 1 candy.
  - Child 0 has rating 1 > 0, so child 0 needs at least 2 candies.
  - Child 2 has rating 2 > 0, so child 2 needs at least 2 candies.
  - Total allocation is `[2, 1, 2]`, sum is 5.
- Consider `ratings = [1, 2, 2]`:
  - Left to right: child 0 gets 1, child 1 gets 2.
  - Child 2 has rating 2 equal to child 1; equal ratings do not force child 2 to exceed child 1. Child 2 can simply receive 1 candy.
  - Total allocation is `[1, 2, 1]`, sum is 4.

## Brute force
A brute-force simulation could initialize every child with 1 candy and repeatedly scan adjacent pairs. Whenever `ratings[i] > ratings[i-1]` but `candies[i] <= candies[i-1]`, we increment `candies[i]`. We repeat until no constraints are violated. In the worst case of a strictly decreasing sequence of length `n`, this requires `O(n)` passes, yielding `O(n^2)` time. We want a linear `O(n)` solution.

## The key observation
Each child `i` has at most two local constraints: one with the left neighbour `i - 1` and one with the right neighbour `i + 1`. We can decouple these two directional constraints. A left-to-right pass ensures that whenever `ratings[i] > ratings[i - 1]`, `candies[i] = candies[i - 1] + 1`. A right-to-left pass ensures that whenever `ratings[i] > ratings[i + 1]`, `candies[i] >= candies[i + 1] + 1`. Taking `candies[i] = max(left_pass[i], right_pass[i])` simultaneously satisfies both constraints with the minimal possible candies.

## Optimal approach
1. Allocate an array `candies` of size `n`, initializing every value to 1.
2. Traverse left to right from index `1` to `n - 1`:
   - If `ratings[i] > ratings[i - 1]`, set `candies[i] = candies[i - 1] + 1`.
3. Traverse right to left from index `n - 2` down to `0`:
   - If `ratings[i] > ratings[i + 1]`, update `candies[i] = max(candies[i], candies[i + 1] + 1)`.
4. Sum all values in `candies` and return the total sum.

Complexity:
- Time: `O(n)` because we make two linear passes over the array.
- Space: `O(n)` auxiliary space to store the candy counts.

## Code walkthrough
- `vector<int> c(n, 1);` initializes every child to the minimum allowed candy count of 1.
- First loop `for (int i = 1; i < n; i++)`:
  - Checks if child `i` outranks child `i - 1`. If so, `c[i] = c[i - 1] + 1`.
- Second loop `for (int i = n - 2; i >= 0; i--)`:
  - Checks if child `i` outranks child `i + 1`. If so, updates `c[i] = max(c[i], c[i + 1] + 1)`.
- Summing `total += x` over `c` yields the minimum total candies needed.

## Test it out loud
- Test with single child `[7]`: Both loops do not execute; returns 1.
- Test with all identical ratings `[3, 3, 3]`: Neither condition fires; returns `1 + 1 + 1 = 3`.
- Test with strictly increasing `[1, 2, 3, 4]`: First pass produces `[1, 2, 3, 4]`, second pass makes no changes; returns 10.
- Test with strictly decreasing `[4, 3, 2, 1]`: First pass stays `[1, 1, 1, 1]`, second pass updates to `[4, 3, 2, 1]`; returns 10.
- Test with mountain shape `[1, 3, 2, 2, 1]`: First pass gives `[1, 2, 1, 1, 1]`, second pass updates `c[1] = max(2, 1 + 1) = 2`, `c[3] = max(1, 1 + 1) = 2`, yielding `[1, 2, 1, 2, 1]` with sum 7.

## Follow-ups
- Can we solve this in `O(1)` extra auxiliary space?
  - Yes, by tracking slopes (up-count, down-count, peak) in a single pass.
- What if children are arranged in a circular table?
  - Find a local minimum index to break the circle into an open line and extend the passes.

## Common mistakes
- Resetting `candies[i] = candies[i + 1] + 1` during the right-to-left pass instead of taking the maximum with the existing value from the left-to-right pass, destroying previous valid counts.
- Forcing children with equal ratings to have different candy amounts.
