## Clarify first
- How many nodes were swapped? Exactly two nodes had their values swapped.
- Does the structure or topology of the tree change? No, only the values of the two swapped nodes need to be swapped back.
- Can values be negative? Yes, values range across standard 32-bit signed integers.
- What space complexity is expected? O(h) using standard recursion or O(1) auxiliary space using Morris traversal.

## Examples to say out loud
- Consider tree `[1, 3, null, null, 2]`:
  - An inorder traversal gives `[3, 2, 1]`.
  - In a valid BST, inorder traversal is strictly increasing.
  - Here `3 > 2` (first violation) and `2 > 1` (second violation).
  - The swapped nodes are 3 and 1. Swapping them yields inorder `[1, 2, 3]`, restoring the tree to `[3, 1, null, null, 2]`.
- Adjacent swap example: `[3, 1, 4, null, null, 2]`.
  - Inorder sequence: `[1, 3, 2, 4]`.
  - Only one descent occurs: `3 > 2`. Swapping 3 and 2 restores order: `[1, 2, 3, 4]`.

## Brute force
A brute force approach performs an inorder traversal and stores all nodes in a list `nodes`. It copies their values into an array, sorts the array in O(n log n) time, and then rewrites the sorted values back into the nodes in order. While this runs in O(n log n) time, it uses O(n) auxiliary space to store all tree nodes. We can identify the two swapped nodes directly in O(n) time and O(h) stack space by tracking inversions during the traversal.

## The key observation
An inorder traversal of a properly formed Binary Search Tree visits values in strictly monotonically increasing order. Swapping two node values creates inversions (descents where `prev->val > cur->val`):
1. If the two swapped nodes are non-adjacent in the inorder sequence: exactly two descents occur. In the first descent, the larger value was swapped forward, so `first = prev`. In the second descent, the smaller value was swapped backward, so `second = cur`.
2. If the two swapped nodes are adjacent: only one descent occurs. Here, `first = prev` and `second = cur`.
Setting `first = prev` on the very first violation and always updating `second = cur` on every violation seamlessly handles both adjacent and non-adjacent cases.

## Optimal approach
1. Maintain three node pointers: `prev = nullptr`, `first = nullptr`, and `second = nullptr`.
2. Perform an inorder traversal:
   - Recursively traverse the left subtree.
   - At the current node `n`:
     - If `prev` exists and `prev->val > n->val`:
       - If `first` is null, set `first = prev`.
       - Always set `second = n`.
     - Update `prev = n`.
   - Recursively traverse the right subtree.
3. After the traversal completes, swap the values `first->val` and `second->val`.
4. Return `root`.

Complexity:
- Time complexity: O(n) because each node is visited once during the inorder traversal.
- Space complexity: O(h) recursion stack space, where h is tree height (O(log n) balanced, O(n) worst-case). Morris traversal can reduce this to O(1).

## Code walkthrough
- `walk(n->left)`: Traverses left subtree first to honor inorder sequence.
- `if (prev && prev->val > n->val)`: Identifies when increasing order is violated.
- `if (!first) first = prev`: Captures the first culprit node (the larger misplaced value) on the first descent.
- `second = n`: Captures the second culprit node (the smaller misplaced value) on the latest descent.
- `prev = n`: Updates the predecessor pointer before visiting the right subtree.
- `swap(first->val, second->val)`: Restores correct values in place.

## Test it out loud
- Test adjacent swap `[1, 2]` where values are swapped to root 2, child 1:
  - Inorder visits 1, then 2. If given `[2, 1]` (root 1, left child 2):
  - Inorder visits node 2, then node 1.
  - Descent detected: `prev (2) > cur (1)`.
  - `first` becomes 2, `second` becomes 1.
  - End of walk: swap 2 and 1. Tree restored. Correct.
- Test non-adjacent swap `[3, 1, 4, null, null, 2]`:
  - Inorder sequence `[1, 3, 2, 4]`.
  - At 2: `prev (3) > cur (2)`. `first = 3`, `second = 2`.
  - At 4: `prev (2) < cur (4)`. No violation.
  - Swapping 3 and 2 gives `[1, 2, 3, 4]`. Correct.

## Follow-ups
- How can we achieve true O(1) auxiliary space? Use Morris Inorder Traversal, which temporarily modifies null right pointers of leaf nodes to point to their inorder successors (creating threaded binary trees) and restores them before returning.
- What if three or more nodes were swapped? General cycle decomposition of the permutation would be required after sorting the extracted values.

## Common mistakes
- Updating `first` on every violation rather than only on the first violation.
- Breaking the traversal early after finding one violation, which fails when the swapped nodes are non-adjacent and produce two separate violations.
