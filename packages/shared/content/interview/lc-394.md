## Clarify first

- Can brackets be nested? Yes, expressions like `2[a2[b]]` are possible and must be decoded from the inside out.
- Can `k` have multiple digits? Yes, counts like `10[a]` can appear, so numbers must be accumulated digit by digit.
- Is the input string always syntactically valid? Yes, the problem guarantees the input format is always valid and balanced.
- Can letters appear outside of brackets? Yes, characters can appear without repeating brackets, such as `3[a]2[bc]`.

## Examples to say out loud

- Nested repeats: `s = "2[a2[b]]c"`.
  - Inner part `2[b]` decodes to `"bb"`.
  - Outer part `a2[b]` becomes `"abb"`, repeated 2 times is `"abbabb"`.
  - Appending `'c'` yields `"abbabbc"`.
- Multi-digit count: `s = "10[a]"`. Decodes to 10 `'a'`s: `"aaaaaaaaaa"`.
- Plain characters without repeat: `s = "abc"`. Returns `"abc"`.

## Brute force

A brute-force strategy repeatedly searches for the innermost closing bracket `]`, finds its matching opening bracket `[`, extracts the multiplier `k`, expands that specific inner substring, replaces that portion in the string, and repeats until no brackets remain. In each replacement step, creating new strings takes `O(n)` time, and there can be up to `n` nesting levels, which can lead to quadratic or worse time complexity.

## The key observation

Brackets denote a hierarchical context: encountering an open bracket `[` saves the current working string and the associated repetition factor `k` onto a stack, then clears the current string to begin decoding the new inner scope. Encountering a closing bracket `]` finalizes the inner scope: pop the saved `(previous_string, k)` from the stack, duplicate the inner string `k` times, and append it to `previous_string`.

## Optimal approach

1. Initialize a stack `st` storing pairs of `(string, int)`.
2. Initialize `cur = ""` (the current working string) and `num = 0` (the current multiplier accumulator).
3. Iterate through each character `c` in string `s`:
   a. If `c` is a digit: `num = num * 10 + (c - '0')`.
   b. If `c == '['`:
      - Push the pair `(cur, num)` onto `st`.
      - Reset `cur = ""` and `num = 0`.
   c. If `c == ']'`:
      - Pop `(prev, k)` from `st`.
      - Form repeated string `rep` by concatenating `cur` exactly `k` times.
      - Set `cur = prev + rep`.
   d. Otherwise (`c` is a letter):
      - Append `c` to `cur`.
4. Return `cur`.

Complexity:
- Time: `O(\text{output length})` because every character in the decoded string is written and copied a constant number of times.
- Space: `O(\text{output length})` auxiliary space to buffer strings and stack contexts.

## Code walkthrough

In the reference implementation:
- `vector<pair<string, int>> st;`: manages the stack frames of enclosing text and repeat counts.
- `if (isdigit(c)) num = num * 10 + (c - '0');`: parses multi-digit integers.
- `else if (c == '[') { st.push_back({cur, num}); cur.clear(); num = 0; }`: suspends outer text and saves multiplier upon entering a new bracket tier.
- `else if (c == ']')`: pops outer context, multiplies the completed inner segment, and appends to outer context.
- `else cur += c;`: appends raw characters to the active tier.

## Test it out loud

- `s = "3[a]2[bc]"`:
  - `3`, `'['`: push `("", 3)`, `cur = ""`.
  - `'a'`: `cur = "a"`.
  - `']'`: pop `("", 3)`, `cur = "" + "a" * 3 = "aaa"`.
  - `2`, `'['`: push `("aaa", 2)`, `cur = ""`.
  - `"bc"`: `cur = "bc"`.
  - `']'`: pop `("aaa", 2)`, `cur = "aaa" + "bc" * 2 = "aaabcbc"`.
  - Returns `"aaabcbc"`.
- `s = "2[a2[b]]"`:
  - Level 1: push `("", 2)`.
  - Inner `'a'`: `cur = "a"`.
  - Level 2: `2`, `'['` -> push `("a", 2)`, `cur = ""`.
  - Inner `'b'`: `cur = "b"`.
  - First `']'`: pop `("a", 2)` -> `cur = "a" + "bb" = "abb"`.
  - Second `']'`: pop `("", 2)` -> `cur = "" + "abb" * 2 = "abbabb"`.
  - Returns `"abbabb"`.

## Follow-ups

- How would you implement this recursively without an explicit stack?
  Use a recursive helper that takes the string index as a reference, recurses on `'['`, and returns when encountering `']'` or string end.
- What if brackets can be mismatched or invalid?
  Validate syntax before decoding or throw errors when popping an empty stack.

## Common mistakes

- Resetting `num` too late or failing to handle multi-digit numbers (assuming `k < 10`).
- Overwriting `cur` on `']'` without prepending `prev`, which loses the enclosing context before the bracket.
- String slicing with regex or string replacement, degrading performance on deeply nested structures.
