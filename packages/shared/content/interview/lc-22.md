## Clarify first

- What does the integer $n$ represent? (The number of pairs of parentheses, producing strings of length $2n$).
- What are the constraints on $n$? ($1 \le n \le 8$).
- What defines a "well-formed" combination? (Every prefix has count of `'('` $\ge$ count of `')'`, and the total count of `'('` equals the total count of `')'` equals $n$).
- In what order should the combinations be returned? (Any order is acceptable).
- Can $n$ be 0? (Constraints state $n \ge 1$; for $n = 0$, the output would be `[""]`).

## Examples to say out loud

- Base case $n = 1$: Only 1 pair: `"()"`.
- Two pairs $n = 2$: Length is 4. Valid options are `"(())"` and `"()()"`.
- Three pairs $n = 3$: Length is 6. Produces 5 valid strings: `"((()))"`, `"(()())"`, `"(())()"`, `"()(())"`, `"()()()"`.

## Brute force

A naive brute force generates all $2^{2n}$ binary sequences of length $2n$ consisting of `'('` and `')'`. For each generated sequence, it checks whether the string is well-formed using a balance counter in $O(n)$ time. The total time complexity would be $O(n \cdot 2^{2n}) = O(n \cdot 4^n)$. For $n = 8$, $2^{16} = 65,536$ sequences are generated, of which only 1,430 are valid, wasting significant computation on invalid sequences like `")))..."`.

## The key observation

Instead of generating invalid sequences and filtering them afterward, we prune the recursion tree so that only valid prefixes are ever explored. At any point in the backtracking recursion, two invariants dictate our choices:
1. We can append `'('` if and only if the number of open brackets used so far is strictly less than $n$ (`open < n`).
2. We can append `')'` if and only if the number of close brackets used so far is strictly less than the number of open brackets (`close < open`).
By enforcing these two rules at each step, every branch that reaches length $2n$ is guaranteed to be a well-formed combination without needing validation.

## Optimal approach

1. Initialize an empty result list `res` and an empty string buffer `cur`.
2. Define a backtracking function `dfs(open, close, n, cur)`:
   - Base case: If `cur.length() == 2 * n`, append `cur` to `res` and return.
   - If `open < n`:
     - Append `'('` to `cur`.
     - Recurse: `dfs(open + 1, close, n, cur)`.
     - Backtrack: remove `'('` from `cur`.
   - If `close < open`:
     - Append `')'` to `cur`.
     - Recurse: `dfs(open, close + 1, n, cur)`.
     - Backtrack: remove `')'` from `cur`.
3. Call `dfs(0, 0, n, cur)` and return `res`.

Complexity:
- Time: $O(\frac{4^n}{\sqrt{n}})$ time, which matches the $n$-th Catalan number $C_n = \frac{1}{n+1}\binom{2n}{n} \approx \frac{4^n}{n\sqrt{\pi n}}$. Generating each valid string takes $O(n)$ work, so the total time is $O(n \cdot C_n) = O(\frac{4^n}{\sqrt{n}})$. For $n = 8$, $C_8 = 1430$, executing in under 2 ms.
- Space: $O(n)$ auxiliary space for the recursion call stack and string buffer of depth $2n$.

## Code walkthrough

In the reference implementation:
- `dfs(open, close, n, cur)`: maintains the counts of opening and closing brackets placed so far.
- `if ((int)cur.size() == 2 * n)`: base case triggers when both $n$ pairs are placed.
- `if (open < n)`: allows adding an open bracket as long as the quota $n$ has not been exhausted.
- `if (close < open)`: ensures a closing bracket is placed only when it can match an existing unmatched open bracket.
- `cur.pop_back()`: restores string buffer state for clean backtracking.

## Test it out loud

- $n = 1$:
  - `open=0, close=0`: adds `'('`.
  - `open=1, close=0`: `open < 1` is false; `close < open` (0 < 1) is true $\to$ adds `')'`.
  - `open=1, close=1`: length is 2, records `"()"`. Returns `["()"]`.
- $n = 2$:
  - Starts with `"("`. Branches to `"(("` and `"()"`.
  - `"(("` forces `"))"` $\to$ `"(())"`.
  - `"()"` branches to `"()("` $\to$ `"()()"`.
  - Outputs `["(())", "()()"]`.

## Follow-ups

- How many combinations are generated for general $n$?
  The number of well-formed parentheses strings is the Catalan number $C_n = \frac{1}{n+1} \binom{2n}{n}$.
- Can we generate combinations iteratively?
  Yes, via closure form dynamic programming: any valid string of length $2n$ can be uniquely written as `(A)B` where $A$ has $k$ pairs and $B$ has $n - 1 - k$ pairs ($0 \le k < n$).
- What if there are multiple types of parentheses (e.g. `()`, `[]`, `{}`)?
  A simple integer counter no longer suffices; a character stack is needed to track the last unclosed bracket type.

## Common mistakes

- Using `close < n` instead of `close < open`, allowing closing brackets to be placed before opening brackets (generating invalid strings like `")("` ).
- Allocating new strings on every function call instead of passing a mutable string buffer and popping back.
- Generating all $2^{2n}$ strings first and filtering with a stack, leading to exponential wasted operations.
